# World Cup Database

Proyek ini dibuat untuk memenuhi tugas sertifikasi **Relational Database** dari **freeCodeCamp**.

## Isi Repositori
* `worldcup.sql` — File *dump* database PostgreSQL (`worldcup`) yang berisi tabel `teams` dan `games`.
* `insert_data.sh` — Skrip Bash untuk memasukkan data pertandingan Piala Dunia dari `games.csv` ke dalam database.
* `queries.sh` — Skrip Bash berisi kueri SQL untuk menampilkan statistik pertandingan dan tim pemenang.
